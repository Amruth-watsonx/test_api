# Test API

A test repository for API development.

## Getting Started

```bash
git clone https://github.com/Amresh37/test_api.git
cd test_api
```

## Features

- Simple test setup
- Ready for development
- Flask-based REST API for employee management

## API Endpoints

- `GET /employees` - Get all employees
- `GET /employees/<id>` - Get employee by ID
- `GET /employees/department/<name>` - Get employees by department
